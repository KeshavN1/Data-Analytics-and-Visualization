## Project Overview
This repository contains my submission for the **Data Analytics and Visualization** assessment. The project explores, cleans, analyses, and visualises a real-world dataset to uncover actionable insights and patterns using Python in Google Colab.

## Objectives
* **Data Cleaning & Preprocessing:** Handle missing values, remove duplicates, and format data types for accurate analysis.
* **Exploratory Data Analysis (EDA):** Calculate summary statistics and examine distributions and correlations across key variables.
* **Data Visualisation:** Create clear, informative charts and graphs to communicate trends and findings effectively.
* **Insight Generation:** Summarise key takeaways and provide data-driven conclusions based on the visual evidence.

## Technologies & Libraries Used
* **Environment:** Google Colab / Python 3
* **Data Manipulation:** `pandas`, `numpy`
* **Data Visualisation:** `matplotlib`, `seaborn`, `plotly`

## How to Run the Notebook
1. **Via Google Colab (Recommended):** Click the **Open In Colab** badge at the top of this file to launch and run the notebook directly in your browser.
2. **Locally:**
   * Clone this repository:
     ```bash
     git clone https://github.com
     ```
   * Install the required libraries:
     ```bash
     pip install pandas numpy matplotlib seaborn plotly
     ```
   * Open the `.ipynb` file in Jupyter Notebook or VS Code and run all cells.
